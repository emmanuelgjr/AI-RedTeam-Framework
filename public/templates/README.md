# Templates

This directory hosts downloadable template artifacts (Word, PowerPoint, Excel).

In v0.1, the Engagement Planner (`/planner`) generates a fully populated Rules
of Engagement document directly. The static templates listed on the `/templates`
page will be populated progressively in v0.2 and v0.3 as the templates pass
review.

When uploaded, files follow this naming convention:

- `ai-redteam-charter.docx`
- `roe-master-template.docx`
- `raci-matrix.xlsx`
- `engagement-brief-1pager.docx`
- `daily-standup-note.md`
- `exit-briefing-deck.pptx`
- `exec-summary-report.docx`
- `audit-findings-report.docx`
- `technical-findings-report.docx`
- `quarterly-program-report.docx`
